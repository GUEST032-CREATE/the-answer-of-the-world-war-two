# The Answer of the World War Two

Una wiki de consulta abierta sobre la Segunda Guerra Mundial (1939-1945): batallas, investigaciones históricas y contexto de cada frente del conflicto.

## Estructura

- [`battles/`](battles/README.md) — Ficha de cada batalla: fechas, bandos, comandantes, desarrollo y consecuencias.
- [`research/`](research/README.md) — Artículos de investigación sobre temas más amplios: causas, economía de guerra, tecnología, frentes, tratados, etc.

## Cómo contribuir

1. Crea una rama para tu cambio.
2. Añade o edita el archivo Markdown correspondiente dentro de `battles/` o `research/`.
3. Actualiza el índice correspondiente para enlazar tu nueva página.
4. Abre un Pull Request describiendo la fuente y el alcance del contenido.

## Objetivo

Mantener información verificable, neutral y bien organizada, con cada página enfocada en un evento o tema concreto.
